# Jawline

Check foundation against your face and the bottles you already own
before you buy. It tells you when it can't tell.

A purchase-decision engine for one foundation, built on the YouCam
API for the YouCam API Skin AI & eCommerce VTO Hackathon.

Status: phase 1 scaffold. Server-side YouCam client skeleton, unit
ledger, shade catalog, and fixture/replay plumbing. No live API calls
are made yet; see the day-1 probe checklist in the full README
(expanded as the build lands).
